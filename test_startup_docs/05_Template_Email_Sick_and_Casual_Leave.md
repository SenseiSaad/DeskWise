# Official Leave & Absence Email Template

**Template type:** email  
**Document code:** TPL-STARTUP-LEAVE-EMAIL  
**Owner:** People & Operations  
**Instructions:** Replace every [Field name] with the employee's profile details or request details. Keep unknown values as [Field name] placeholders.

---

## Template

```text
Subject: [Leave Type] Leave Request — [Full Name] ([Start Date] to [End Date])

Hi [Manager's Name],

I would like to request [Leave Type] leave from [Start Date] through [End Date] ([Number of Days] working day(s)).

- Reason: [Brief Reason]
- Handover / Coverage: [Colleague's Name] will cover urgent tasks while I am away.
- Reachable for emergencies: [Email]

Please let me know if this works with our schedule.

Best regards,
[Full Name]
[Your Job Title], [Department]
[Company]
```

## Field guide

| Placeholder | Source |
| --- | --- |
| [Leave Type] | Request detail (Sick / Annual / Casual) |
| [Full Name] | Employee profile |
| [Start Date] | Request detail |
| [End Date] | Request detail |
| [Number of Days] | Request detail |
| [Manager's Name] | Employee profile or request detail |
| [Brief Reason] | Request detail |
| [Colleague's Name] | Request detail |
| [Email] | Employee profile |
| [Your Job Title] | Employee profile |
| [Department] | Employee profile |
| [Company] | Company profile |
